# Veebileheprojekt
Sellesse repositooriumisse hakkab tiim "ratas" laadima üles aine Sissejuhatus erialasse veebileheprojekti jooksul valminud veebilehte, koos html, css ning python backendiga.  
Kõik eelnevalt plaani märgitud väärtused on meie jaoks endiselt olulised, kuid proovime rõhku panna rohkem õigeaegsele töö valmimisele ning tähtaegadest kinni hoidmisele.
